# 🥁 Drum Tuner AI

**Автоматизация рабочего места барабанщика**

---

## 📖 О программе

Данный проект содержит программу, позволяющую **определять частоту удара по барабану через микрофон**, сравнивать её с эталонными настройками легендарных метал-барабанщиков и получать рекомендации по настройке пластиков. Полученные данные предоставляются в виде **наглядной статистики и графиков**, что позволяет барабанщику легко отслеживать текущее состояние настройки и настраивать инструмент **с точностью до Герца**.

---

## ⚙️ Основные функции программы

- 🎤 **Мониторинг частоты удара, амплитуды сигнала и уровня громкости** в реальном времени
- 📊 **Предоставление данных** в виде графиков спектра и визуальной схемы расположения болтов
- ✅ **Уведомления пользователю** о текущем состоянии настройки: правильно или неправильно
- 🎯 **Установка оптимальных параметров** для поддержания эталонного звука: частота, допуск, тип пластика
- 💾 **Сохранение всех данных** в базах данных для последующего анализа и прогнозирования

---

## 🚀 Использование программы

Для запуска необходимо установить все зависимости, а затем запустить файл `DrumTuner.exe`. После этого можно приступать к **мониторингу состояния барабана и анализу полученных данных**.
