# Drum Tuner AI

Программа для автонастройки барабанов. Определяет частоту удара через микрофон, сравнивает с эталонами легендарных метал-барабанщиков и даёт рекомендации по настройке.

## Основные функции
- Определение частоты удара (YIN алгоритм)
- Визуализация спектра и схемы болтов
- База из 10 легендарных барабанщиков
- ИИ-обучение на истории замеров
- Экспорт/импорт данных в JSON
